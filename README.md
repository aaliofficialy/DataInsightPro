# DataInsightPro

Professional static website for data analytics and business intelligence.

## Included
- Data analysis landing page
- Browser-based CSV analyzer
- Executive dashboard showcase
- Excel analytics overview
- Data cleaning guidance
- KPI reporting page
- Analytics case studies
- Contact / project inquiry page
- Responsive dark analytics UI

## GitHub Pages
Go to **Settings → Pages → Deploy from a branch → main → / (root)** and save.

Expected site URL:
`https://aaliofficialy.github.io/DataInsightPro/`

## Notes
The CSV analyzer processes the selected CSV locally in the browser; no server upload is required.
