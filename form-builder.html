How entries work

Local mode (no Google Sheet): create a form, generate the link, submit entries, view them in Entries, correct mistakes, delete records and download CSV/Excel/PDF/Word. Nothing external is required.

Shared mode (optional): connect the included Google Apps Script Web App if you want submissions from different PCs/phones to appear in one shared Google Sheet. The generated form still keeps a local copy of each submission.
